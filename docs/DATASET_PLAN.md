# Dataset plan
Sources: public Python and Java GitHub repositories. Record commit SHA and licence metadata.
Split by repository, never random chunks. Automated symbol-template QA are candidates only.
Human-review labels before training; manually author/review evaluation QA, including
single-file, cross-file, multi-hop and unanswerable questions. Document collection date,
licences, filtering, deduplication, secret scan limitations, synthetic generation and splits.
